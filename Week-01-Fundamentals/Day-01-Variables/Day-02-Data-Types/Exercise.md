# Day 02 — JavaScript Exercises

## Exercise 1: Identify Data Types

Create variables for the following information:

1. Your name.
2. Your age.
3. Your CGPA.
4. Whether you are a CS student.
5. Your university name.
6. An unassigned variable.
7. A null value.

**Task:**

- Print all variables.
- Check their data types using `typeof`.

## Exercise 2: Array Practice

Create an array containing five university subjects.

**Tasks:**

1. Print the complete array.
2. Print the first subject.
3. Print the third subject.
4. Check its type using `typeof`.
5. Check whether it is an array using `Array.isArray()`.

## Exercise 3: Object Practice

Create a student object containing:

- name
- age
- university
- semester
- CGPA

**Tasks:**

1. Print the complete object.
2. Print the student's name.
3. Print the student's CGPA.
4. Check its data type.

## Exercise 4: Predict the Output

Predict the output before running the code.

```javascript
console.log(typeof "Hello");
console.log(typeof 25);
console.log(typeof true);
console.log(typeof undefined);
console.log(typeof null);
console.log(typeof []);
console.log(typeof {});
console.log(Array.isArray([]));
```

## Exercise 5: Find and Correct the Error

Find the error and correct the code.

```javascript
let studentName = "Sara";
let age = 20;

console.log(typeOf studentName);
console.log(typeof age);
```

## Exercise 6: AgriNova Practical Task

Create a farmer object containing:

- farmerName
- district
- farmArea
- isRegistered
- availableCrops

**Tasks:**

1. Print the farmer's complete information.
2. Print the farmer's name.
3. Print available crops.
4. Check the data types of all properties.
5. Check whether availableCrops is an array.

## Learning Outcomes

After completing these exercises, I should be able to:

- Understand JavaScript primitive data types.
- Understand non-primitive data types.
- Use the typeof operator.
- Create arrays and objects.
- Use Array.isArray().
- Identify and correct basic JavaScript errors.

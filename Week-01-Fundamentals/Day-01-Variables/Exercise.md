## PRACTICAL EXERCISES

Try solving these exercises yourself before checking any solutions.

## Exercise 1: Basic Variables

Create three variables:

- Your name.
- Your age.
- Your university name.

Print all three using console.log().

## Exercise 2: Reassignment

Declare a variable using let.

- Store your current semester.
- Change it to the next semester.
- Print the updated value.

## Exercise 3: const

Declare a constant named country and store "Pakistan".

Print its value.

## Exercise 4: var, let and const

Create three variables using var, let, and const.

Try changing their values and observe the results.

## Exercise 5: Scope

Predict the output before running this code.

```javascript
{
  let x = 10;
  const y = 20;
  var z = 30;
}

console.log(z);
console.log(x);
console.log(y);
```

Explain why each output occurs.

## Exercise 6: Mini Project — Student Information System

Create a JavaScript program that stores student information.

Your program should contain:

- Student name.
- Age.
- University.
- Semester.
- CGPA.
- Country.

Print all information using console.log().

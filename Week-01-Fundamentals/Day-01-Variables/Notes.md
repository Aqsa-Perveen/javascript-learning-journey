# Day 01 — JavaScript Variables

## 1. What is a Variable?

A variable is a container used to store data.

## 2. Variable Declaration Keywords

### let

- Used to declare variables.
- Values can be reassigned.

Example:

```javascript
let age = 20;
age = 21;
```

### const

- Used to declare constants.
- Values cannot be reassigned.

Example:

```javascript
const country = "Pakistan";
```

### var

- Older way to declare variables.
- Values can be reassigned.

## 3. Reassignment

Changing the existing value of a variable.

```javascript
let marks = 70;
marks = 85;
```

## 4. console.log()

Used to display output in the console.

```javascript
console.log("Hello JavaScript");
```

## 5. Variable Naming Rules

- Use meaningful names.
- Cannot start with a number.
- Cannot use reserved keywords.
- JavaScript is case-sensitive.
- Use camelCase for multiple words.

Example: `farmerName`

## 6. Important Difference

| let                                      | const                             |
| ---------------------------------------- | --------------------------------- |
| Reassignment allowed                     | Reassignment not allowed          |
| Can be declared without an initial value | Must be initialized when declared |
